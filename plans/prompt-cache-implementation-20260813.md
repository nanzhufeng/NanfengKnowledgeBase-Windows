# Prompt Cache 实施契约

- 唯一目标：提高全库 AI 分类与主题洞察的稳定前缀缓存命中，并形成可核算的逐阶段成本证据。
- 唯一所有者：`src-tauri/src/ai/prompt_cache.rs` 负责 Prompt 稳定前缀、缓存键和供应商请求结构。
- 允许范围：AI Rust 客户端、用量模型、SQLite 下一号迁移、逐阶段账本、定向测试与动态交接。
- 禁止范围：正式数据库、真实资料、API Key输出、发布、安装、视觉与业务结构调整。经南烛枫继续授权后，只允许使用合成内容和固定费用上限执行隔离真实API金丝雀。
- 保持不变：AI 负责可见语义内容；原始材料不覆盖；模型路线按任务开始时冻结；已完成批次优先由本地断点复用。千问仅在逐篇档案和批量归属关闭思考；全库结构、主题整合与主题洞察保持默认思考。
- 最小验证：Prompt 合同测试、推理阶段策略、usage 解析与成本测试、迁移/仓储测试、Rust 全库测试、格式与 diff 检查；真实金丝雀只输出Token、缓存、reasoning、耗时和可用成本字段，不保存响应正文。

- 正式验收：migration v14已应用并完成备份、完整性、外键、业务计数和幂等验证；2条真实来源/68个正式主题的千问Flash归属首写`4119`、热请求命中`4119`，前缀命中率98.66%，逐阶段账本4/4一致，来源/主题/taxonomy修订未改变。

- 待验证：长期真实批次累计命中率、全库规模质量抽检和美元账单；当前2条一致性是小样本真实证据，不自动开始全库生成或应用修订。
