# 设计系统

## 布局

- 单一全高左侧导航。
- 记录工作区采用“搜索与列表 + 详情”两列；导航与列表共同形成视觉上的三栏。
- 1440 宽度时记录列约 424 px，其余空间交给详情阅读。

## 颜色

- 深普鲁士蓝：身份和全局导航。
- 靛蓝：选中、主要操作和结构关联。
- 红色：当前判断。
- 绿色：已确认事实。
- 橙色：待验证问题。
- 冷灰：工作区背景和次级信息。

## 卡片层级

- 静止：边框 + 清晰但克制的底部投影。
- 悬停：`translateY(-2px)`，增强投影并显示快捷操作。
- 按下：`scale(0.985)`，回落至原平面。
- 选中：稳定靛蓝描边与更深一级的底部投影。
- 折叠/展开：仅改变内容高度和透明度，不旋转或弹跳整张卡片。

## 动效

- 高频反馈约 120–180 ms。
- 折叠与展开约 200–260 ms。
- 位移使用 `cubic-bezier(0.23, 1, 0.32, 1)` 或 `cubic-bezier(0.77, 0, 0.175, 1)`。
- 悬停仅在精细指针设备启用。
- `prefers-reduced-motion` 下移除位移和长动画。
