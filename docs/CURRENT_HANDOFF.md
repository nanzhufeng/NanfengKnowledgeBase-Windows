## 1. 当前结论

1. 产品方向已经锁定为三个核心入口：`知识视图 / 来源档案 / 主题管理`。它们不是旧页面改名，而是同一条知识生产链的三个阅读入口。
2. 自动整理是默认前提；人工只处理低置信、冲突或无合适主题的例外。旧记录中心、人工分类中心和 CRUD 首屏方向已明确否决。
3. 当前未提交工作区已按产品主规格、升级思路文档和四张最终功能图重组三个入口：
   - `知识视图`默认`竞争假设`，可切换`判断演变 / 笔记与来源 / 决策版本`；
   - `来源档案`以紧凑列表定位和大幅正文阅读为主体，自动整理信息压缩为必要元数据；
   - `主题管理`以主题边界、自动归类依据、层级关系、别名和可执行待处理事项为主体。
4. 知识视图四个状态已按单一职责收口：`竞争假设`只管假设/证据/有效期/问题，`判断演变`只管判断变化与唯一时间线，`笔记与来源`只管正文与来源，`决策版本`只管决策账本；中栏继续保持领域→主题，不重复增加笔记层。
