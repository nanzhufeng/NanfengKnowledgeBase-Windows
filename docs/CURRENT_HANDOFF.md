# 当前交接

## 当前状态

- 产品：南枫情报台 `0.1.0`，本地优先 Windows 桌面 MVP。
- 技术：Tauri 2 + React/TypeScript + Rust rusqlite/FTS5。
- 数据所有权：桌面端统一经 `RecordRepository` 调用 Rust 命令；浏览器适配器只服务 UI 调试。
- 当前交付阶段：先用 `启动南枫情报台-测试版.bat` 验收；用户明确确认通过后才能生成安装包。
- 工作区保护：接手时先检查 Git 状态；不得清理、重置或覆盖未知改动。

## 已实现

- SQLite 迁移、受控数据目录、记录 CRUD、全字段编辑、650 ms 自动保存、收藏、状态、标签与来源。
- 版本追加/预览/恢复为新版本；回收站恢复；完整标题确认永久删除。
- FTS5 trigram 与 1–2 字 LIKE 回退；范围筛选、排序和搜索高亮。
- JSON/Markdown/TXT/HTML 导入；原文件先归档，再做 SHA-256、编码识别、预览、字段映射、哈希查重和导入日志。
- 导入记录详情可直接读取现有 `summary` 与 `sourceText`：Claude 会话 JSON 会显示摘要、消息数、原文预览及完整用户/助手对话，无需重新导入。
- 单条 Markdown/JSON、全量 JSON 导出；SQLite 一致性备份；恢复前安全备份和恢复后完整性校验。
- 设置页只保留已落地的数据维护、标签管理和真实快捷键入口；已移除无行为的收录箱、外观、提醒与隐私占位项。

## 验证等级

- 契约/构建：前端仓库 2/2；Sites 4/4；Rust 7/7；TypeScript、Vite 生产构建和 Rust 格式检查通过。
- 浏览器运行：新增、中文搜索、自动保存、版本、回收站、恢复和永久删除路径通过；测试数据已清理。
- 真实 Tauri 桌面：隔离数据目录下完成新建、判断自动保存、重启持久化、单条 Markdown 导出、真实 JSON 文件选择、原文件归档、字段映射、SQLite 写入和数据库备份。
- 真实 Tauri 桌面：使用隔离的 282 条真实导入记录验证列表菜单完整显示、切换标题关闭旧菜单、摘要/原文预览和完整会话弹窗。
- 视觉：关联线两端 8 px 锚点圆心与 1 px 水平线同轴；深色侧栏、冷灰底、白卡、底部阴影和卡片动效保持。
- BAT 入口：默认启动现有 release 测试程序；传入 `--rebuild` 时仅执行 `tauri build --no-bundle`，不会生成安装包。

## 边界与风险

- 本轮桌面验收使用 `.runtime-qa/data` 隔离目录，不触碰用户正式数据。
- 恢复逻辑由 Rust 测试覆盖；桌面 UI 已检查二次确认，但没有在用户正式数据上执行恢复。
- 不把此前的预构建安装包作为当前交付物；必须等用户完成 BAT 试用并明确确认后，再重新生成和验证安装包。
