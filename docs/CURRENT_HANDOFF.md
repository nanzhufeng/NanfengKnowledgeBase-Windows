# 当前交接

## 当前状态

- 产品：南枫情报台 `0.1.0`，本地优先 Windows 桌面 MVP。
- 技术：Tauri 2 + React/TypeScript + Rust rusqlite/FTS5。
- 数据所有权：桌面端统一经 `RecordRepository` 调用 Rust 命令；浏览器适配器只服务 UI 调试。
- 当前交付阶段：先用 `启动南枫情报台-测试版.bat` 验收；用户明确确认通过后才能生成安装包。
- 工作区保护：接手时先检查 Git 状态；不得清理、重置或覆盖未知改动。

## 已实现

- Windows 正式数据默认写入 `D:\南枫情报台`；目标为空时从旧 AppData 无损复制数据库、WAL 与全部受控子目录，旧目录保留；D 盘不可用或迁移失败时回退旧目录。
- SQLite 迁移、受控数据目录、记录 CRUD、全字段编辑、650 ms 自动保存、收藏、状态、标签与来源。
- 左侧新增“我的收藏”真实视图和计数；收藏命令只返回记录号、状态和更新时间，不再跨进程回传大正文，并阻止同一记录的并发重复点击。
- 正式版始终写入受控 `logs` 目录；Rust panic 额外写入 `panic.log`，便于下一次故障保留可诊断证据。
- 版本追加/预览/恢复为新版本；回收站恢复；完整标题确认永久删除。
- FTS5 trigram 与 1–2 字 LIKE 回退；范围筛选、排序和搜索高亮。
- JSON/Markdown/TXT/HTML 导入；原文件先归档，再做 SHA-256、编码识别、预览、字段映射、哈希查重和导入日志。
- 导入记录详情可直接读取现有 `summary` 与 `sourceText`：Claude 会话 JSON 会显示中文摘要、消息数、原文预览及完整用户/助手对话；英文摘要默认隐藏但原值仍保留，无需重新导入。
- 通用导入标题（如 `Conversation Overview`、`Untitled`、`未命名导入记录`）会优先回退到首条用户消息：现有记录仅优化显示、不批量改写数据库；后续导入会直接持久化该标题。
- 单条 Markdown/JSON、全量 JSON 导出；SQLite 一致性备份；恢复前安全备份和恢复后完整性校验。
- 设置页只保留已落地的数据维护、标签管理和真实快捷键入口；已移除无行为的收录箱、外观、提醒与隐私占位项。

## 边界与风险

- 本轮桌面验收使用 `.runtime-qa/favorite-crash-data` 隔离目录，不触碰用户正式数据。
- 当前旧版进程仍在运行，因此没有在本轮直接创建 `D:\南枫情报台` 或迁移正式库；用户关闭旧版并首次启动新测试版时才执行真实迁移。
- 现有 Windows 崩溃转储确认发生过 Rust panic；隔离副本没有稳定复现每次收藏必崩。轻量收藏返回、重复点击锁和正式日志已降低已识别风险，但仍需用户真实路径复测。
- 恢复逻辑由 Rust 测试覆盖；桌面 UI 已检查二次确认，但没有在用户正式数据上执行恢复。
- 不把此前的预构建安装包作为当前交付物；必须等用户完成 BAT 试用并明确确认后，再重新生成和验证安装包。
