# 产品边界

## 核心用户任务

把分散在财报、研究对话、访谈和文件中的判断整理为一条可长期追踪的本地记录，并能快速区分：

- 当前判断
- 已确认事实
- 关键证据
- 待验证问题
- 下一步行动
- 历史版本

产品不是自由笔记软件，也不是 AI 套壳；核心在无模型 API、断网状态下仍应可用。

## 当前阶段

阶段 1 只验证界面与交互骨架。数据使用固定假数据，导入只演示预览和字段映射，不触碰真实文件或持久化存储。

## 第一用户路径

```text
打开全部记录
→ 搜索“资本开支”
→ 选中一条记录
→ 查看结构化详情
→ 编辑当前判断
→ 显示已保存状态
→ 追加并查看历史版本
→ 进入导入中心
→ 载入 JSON 示例
→ 确认字段映射与预计导入结果
```

## 当前成功标准

- 1440 × 900 和 1366 × 768 下主流程可用且无页面级横向溢出。
- 卡片默认、悬停、按下、选中、折叠和展开状态遵循同一套交互规则。
- 搜索、选择、编辑、保存、版本、导入映射、回收站恢复演示可操作。
- 不接真实数据库、API 或文件写入。
