# 产品边界

## 核心用户任务

把分散在财报、研究对话、访谈和文件中的判断整理为一条可长期追踪的本地记录，并能快速区分：

- 当前判断
- 已确认事实
- 关键证据
- 待验证问题
- 下一步行动
- 历史版本

产品不是自由笔记软件，也不是 AI 套壳；核心在无模型 API、断网状态下仍应可用。

## 当前阶段

阶段 1 视觉与交互骨架已经确认。当前实施本地优先桌面 MVP：记录、标签、来源、版本、搜索、导入、导出、备份与恢复均以本机 SQLite 和受控目录为准；浏览器演示仓库仅用于界面检查。

## 第一用户路径

```text
打开全部记录
→ 搜索“资本开支”
→ 选中一条记录
→ 查看结构化详情
→ 编辑当前判断
→ 显示已保存状态
→ 追加并查看历史版本
→ 进入导入中心
→ 载入 JSON 示例
→ 确认字段映射与预计导入结果
```

## MVP 成功标准

- 1440 × 900 和 1366 × 768 下主流程可用且无页面级横向溢出。
- 卡片默认、悬停、按下、选中、折叠和展开状态遵循同一套交互规则。
- 搜索、选择、编辑、自动保存、版本、回收站恢复和确认永久删除在 SQLite 真实链路可操作。
- JSON、Markdown、TXT、HTML 导入先归档原文件并计算 SHA-256，再预览、映射、去重与写入。
- 可导出单条 Markdown/JSON 和全量数据库备份；恢复前自动保护当前数据库并执行完整性检查。
- Windows 安装包可构建，重装/升级不清空用户数据；断网状态不影响核心功能。
