# 长期决策

| 日期 | 决策 | 原因 | 当前影响 |
|---|---|---|---|
| 2026-07-25 | 核心离线可用，不强制模型 API | 降低成本、维护和稳定性风险 | UI 不出现模型依赖 |
| 2026-07-25 | UI 与交互先于数据库 | 先确定真实工作流，减少后续返工 | 阶段 1 全部使用假数据 |
| 2026-07-25 | JSON 是第一优先导入格式 | 适配 ChatGPT 与结构化资料归档 | 首轮实现字段映射演示 |
| 2026-07-25 | 使用单一深色左栏和浅色三栏工作台 | 保留科技质感，同时维持长内容阅读性 | 主界面结构固定 |
| 2026-07-25 | 卡片统一使用向下投影和克制的物理动效 | 提升卡片交互质感，不让界面漂浮失序 | 全部卡片复用共享 Token |
| 2026-07-25 | 红、橙、绿承担语义色，蓝色只作主操作与结构色 | 避免大面积单一蓝色 | 判断/问题/事实分色 |
| 2026-07-25 | 关联只使用细线和锚点 | 保留结构关系但不抢内容 | 选中记录到详情的低调连接 |
| 2026-07-25 | 阶段 1 视觉与交互契约冻结，进入完整本地 MVP | 用户已确认方向并明确要求实施到完成 | 不再以“原型不可写入”为边界 |
| 2026-07-25 | Tauri 2 + Rust rusqlite 是生产数据唯一所有者 | 保持离线、可审计、可迁移并减少双写 | 前端只经 `RecordRepository` 调命令，不直接执行 SQL |
| 2026-07-25 | 浏览器仓库仅作视觉和契约适配器 | 保留快速浏览器 QA，同时避免把演示数据当桌面真相 | 桌面运行必须以 SQLite 结果验收 |
| 2026-07-25 | 删除采用回收站 + 完整标题确认；版本恢复生成新版本 | 保护本地研究资料，避免覆盖历史 | 不允许直接永久删除活动记录或覆盖旧快照 |
