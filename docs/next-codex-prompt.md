## 当前合同

- v109后，主题整合属于`AI Taxonomy Revision`强制结果：每个有归属笔记的主题必须有非空整合正文，`sourceItemIds`必须完整等于该主题全部归属笔记；持久化和应用双重校验。主题管理与主题洞察读取同一份已应用整合和来源，`AI重新整理`不得覆盖它。
- v110后，全库分类每个成功批次立即写入migration v8检查点并累计Token/已知费用；中断后主题管理自动询问继续、放弃或稍后处理，继续只执行剩余批次。模型配置只从设置页保存：主题管理不显示或传递临时模型，断点继续沿用任务已保存的实际模型。主题整合正文仍由AI生成，但`sourceItemIds`只由最终归属确定性绑定，模型返回错误来源ID不得再毁掉整次长任务。旧v109及以前的失败任务没有检查点，不能声称可恢复。
