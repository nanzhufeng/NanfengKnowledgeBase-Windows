## 发现并修复的问题

Windows `tasklist` 的 Image Name 列会把 `nanfeng-knowledge-base.exe` 截断为 `nanfeng-knowledge-base.ex`。BAT 原先按完整进程名过滤输出，导致程序已打开时仍误报“两秒内退出”。

修复后，三处检查均使用 `tasklist` 的精确筛选条件，并对输出匹配稳定前缀 `nanfeng-knowledge-base`。
