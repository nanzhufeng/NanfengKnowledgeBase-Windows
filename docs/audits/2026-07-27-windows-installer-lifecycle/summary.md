## 修复说明

Tauri NSIS 的卸载项按产品名区分。产品从“南枫情报台”改为“南枫知识库”后，默认升级不会识别旧卸载项。`src-tauri/installer-hooks.nsh` 现在：

1. 安装前检测旧版进程，运行中则终止安装；
2. 读取旧版当前用户卸载项并静默卸载旧程序；
3. 旧版卸载失败时停止新版安装；
4. 只处理程序目录与卸载项，不操作独立数据目录。
