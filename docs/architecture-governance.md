# 架构所有权

项目遵循根级 `docs/app-development/architecture-baseline.md`。当前阶段没有真实数据层，以下所有者仅约束 UI 原型，避免进入数据库阶段前形成平行规则。

| 概念 | 产品含义 | 唯一所有者 | 公开入口 | 当前消费者 | 禁止的平行规则 | 最小验证 | 状态 |
|---|---|---|---|---|---|---|---|
| 研究记录假数据 | 列表、详情和搜索使用的演示事实 | `src/mockData.ts` | 导出的记录与详情常量 | 记录列表、详情、搜索 | 页面内复制另一份记录数据 | 搜索和选择结果一致 | 已实现 |
| 当前判断编辑状态 | 阅读、编辑和保存提示的同一段判断 | `App` 的 `judgment/saveState` | `DetailPanel` props | 判断卡、顶部保存状态 | 页面局部各自保存一份文本 | 编辑后两处保存状态一致 | 已实现 |
| 页面导航状态 | 全部记录、导入、回收站和设置的当前位置 | `App` 的 `page` | `Sidebar.onNavigate` | 主区域页面选择 | 各页面自行修改侧栏状态 | 导航与可见页面一致 | 已实现 |
| JSON 导入演示状态 | 空、预览、字段映射三个阶段 | `App` 的 `importStep` | `ImportCenter/JsonMapping` | 导入中心 | 真实解析或文件写入 | 示例可完整走到结果预览 | 已实现 |
| 视觉与动效 Token | 颜色、阴影、时长、缓动与卡片层级 | `src/styles.css :root` 与 `.elevated-card` | 共享 CSS 类 | 全部卡片和控件 | 页面私建同类阴影与动效 | 对照稿和交互状态检查 | 已实现 |

## 入口矩阵

| 入口/消费者 | 是否存在 | 当前影响 | 唯一入口 | 最小验证 |
|---|---|---|---|---|
| 新建、复制、永久删除 | 否 | 不存在 | — | — |
| 编辑当前判断 | 是 | 受影响 | `DetailPanel` | 自动保存提示 |
| JSON 文件导入 | 仅演示 | 保真通道骨架 | `ImportCenter` | 示例映射闭环 |
| 列表、详情、搜索 | 是 | 受影响 | `records/mockData` | 搜索与选中一致 |
| 历史版本 | 仅演示 | 受影响 | `DetailPanel` | 追加后展开 |
| 回收站 | 仅演示 | 受影响 | `TrashPage` | 恢复反馈 |
| 导出、备份、恢复 | 否 | 不存在 | — | — |
| 不同窗口与 DPI | 浏览器原型 | 受影响 | CSS 响应式规则 | 1440×900、1366×768 |
