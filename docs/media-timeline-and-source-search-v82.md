# 媒体时间线、正文定位与视频按需恢复 v84

> 历史专项记录：逐项“点击恢复并播放”与只显示受控附件的时间线已被v89替代。当前合同以`core-workspace-design-baseline.md` 4.6、`architecture-governance.md`和`CURRENT_HANDOFF.md`为准：声明目录完整可见、当前笔记默认自动加载、五类时间线按月分组。

## 已实现

- ChatGPT 对话解析不再只识别图片：视频、音频、普通文件都保留为可见附件声明；并覆盖当前导出真实使用的`message.metadata.attachments[].id/name/size/mime_type`结构。导出包缺少二进制实体时显示明确状态，不再静默消失。
- 新导入的对话日期先取创建时间，更新时间只作回退；当前已导入对话正文页优先显示首条对话消息时间。
- 历史搜索的“全部 / 图片 / 视频 / 音频 / 文件”可进入独立资料时间线，按原笔记日期倒序，并提供本分类内继续搜索和软件内打开。
- 正文搜索有明确的“搜索”按钮，命中后滚动到首个结果并逐字黄色标记。
- 历史视频缺少受控附件实体时，缺失卡本身就是“点击恢复并播放”入口。用户确认后按正文声明的附件唯一 ID，只从这篇笔记对应的原始 ChatGPT ZIP 提取这一条文件，建立来源附件关联并立即打开软件内播放器；重复点击不会重复入库。

## 数据边界

已有记录不会在启动时写回或重建。视频恢复只发生在用户点击具体缺失卡并确认之后，不扫描全库、不批量解压、不覆盖其他附件；恢复失败时清理未完成输出。Codex 构建和自动测试不打开或写入正式数据。

## 验收

1. 双击 `启动南枫知识库-视频附件恢复与播放验收.bat` 前先执行一次 `--prepare`。
2. 在全部笔记的搜索范围中点击“视频”，确认弹出“视频资料”时间线；输入文件名后点击“搜索”。
3. 打开带视频的 ChatGPT 对话：缺失卡应显示“点击恢复并播放”；点击并确认后，卡片切换为原位播放器，同时打开最高层视频预览。关闭预览后仍可在正文原位播放。
4. 输入正文关键词并点击“搜索”，确认首个命中滚动到视口中央并以黄色高亮。
5. 核对跨午夜对话标题下显示的是 7 月 24 日创建日期，而不是 7 月 25 日更新时间。
