# 南枫知识库代码审查

## 审查起点

1. 读取变更 diff、相关测试和当前领域契约；先确认工作区中哪些改动属于本次范围。
2. 以调用链审查，而非只看单个文件：schema/migration → Rust repository → command → TypeScript service → UI → 测试与文档。
3. 将发现按阻断、重要、一般、建议分级；每项附文件位置、触发条件、影响与可执行修复方向。

## 必查清单

- SQLite migration 是否前向兼容、事务完整、可回滚/恢复边界清楚，且未改写已发布 migration。
- Tauri command 是否校验参数、暴露最小能力、返回可诊断错误；服务层是否保持输入输出契约。
- 原始来源、用户编辑与 AI 派生结果是否隔离，应用与撤销是否可追踪。
- 密钥、原始敏感内容和附件路径是否泄露到 SQLite、日志、前端或缓存键。
- Prompt Cache 是否隔离模型、阶段、提示词版本与归一化规则；命中是否可能复用错误语义。
- UI 是否遵守现行设计基线，轻量浮层是否点击外部关闭，失败状态是否可理解。
- 是否有覆盖关键路径的定向测试；文档是否与当前代码或验证结果冲突。

## 输出边界

只陈述可由代码、测试、运行记录或 Git 历史支持的结论。没有发现问题时说明审查范围与未审查范围；未获授权不直接修改代码。
